> I resign effective Friday — after three years, the office plant has been promoted twice, and I refuse to be outranked by a fern.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is deterministic: it always writes the same single line (128 characters) to `/output/entry.txt`. No input, no network, no randomness.
